# Hello, World!

Our first program prints the classic greeting. Every Mojo program starts at `def main():`.

```mojo
def main():
    print("Hello, World!")

    # print accepts multiple values, separated by spaces
    print("The sum of 1 and 2 is", 1 + 2)
```

```text
Hello, World!
The sum of 1 and 2 is 3
```

Run it with `mojo run hello.mojo` — no boilerplate, no hidden runtime.
